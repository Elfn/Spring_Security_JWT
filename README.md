##              											SECURE WEB APPS(API REST) USING JSON WEB TOKEN

A WEB APP IS CONSIST OF 2 PARTS "BACK END" AND "FRONT END"
BACKEND CONCERNED SERVER SIDE(PHP,NODEJS,JEE) , FRONTEND CARES OF IHM CLIENT SIDE(HTML, CSS, JS)
THAT 2 PARTS COMMUNICATE THROUGHT HTTP PROTOCOL


HTTP=> HYPERTEXT TRANSFERT PROTOCOL ALLOWS TO CLIENT TO GET DOCUMENTS FROM SERVER, AND CLIENT CAN ALSO SUBMIT DATA TO SERVER TROUGHT A FORM


=>CLIENT CONNECT TO THE SERVER (THAT CONNECTION CREATES SOCKETS BETWEEN CLEINT AND SERVER )
=>CLIENT ASK A DOCUMENT TO THE SERVER (HTTP REQUEST)
=>SERVER FORWARD A DOCUMENT TO THE CLIENT ASSOCIATED TO SEVERALS INFORMATIONS(STATUS 404, 200......)
=>DECONNECTION(SOCKETS ARE DESTROYED) TO SAVE BANDWIDTH AND FREE SERVER FOR SUBSEQUENS REQUESTS


HTTP REQUEST IS COMPOSED OF > HEADER AND BODY , 
HTTP RESPONSE IS COMPOSED OF > STATUS CODE, HEADER, BODY

HTTP REQUEST HEADER => HOST(DOMAIN NAME), ACCEPT(RESPONSE FORMAT), CONTENT-TYPE(CONTENT FORMAT), COOKIE
